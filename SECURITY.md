# Security Policy

## Reporting Security Issues

We take the security and privacy of Personal Agentic Fleet very seriously.
Because Fleet handles personal workflows, machine diagnostics, and local task automation, we enforce strict local-first isolation and credential separation.

If you discover a potential security vulnerability, please do NOT create a public issue on GitHub. Instead, please report it privately:

1. Open a private security advisory on GitHub under **Security > Advisories > Report a vulnerability**.
2. Or contact the maintainer directly at the email listed on [@macazaka's GitHub profile](https://github.com/macazaka).

We will investigate and respond to vulnerability reports within 48 hours.
